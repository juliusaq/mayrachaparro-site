# ADR-0003: Principles Before Direction

Estado: Accepted

Fecha: 2026-06-30

## Contexto

La arquitectura documental ya separa The Care System como fuente filosofica y North Star como fuente de direccion estrategica.

Durante la revision estrategica se identifico la necesidad de documentar principios permanentes antes de desarrollar la direccion estrategica de largo plazo.

## Decision

Crear `docs/01-care-system/08-principios-del-cuidado.md` como estructura editorial para The 12 Principles of Care.

Actualizar la jerarquia conceptual de referencia:

Antes:

```text
The Care System
↓
North Star
```

Ahora:

```text
The Care System
↓
The 12 Principles
↓
North Star
```

## Consecuencias

- La direccion estrategica debera apoyarse primero en principios permanentes.
- North Star no funcionara como constitucion etica, cultural o estrategica; esa responsabilidad quedara separada.
- Las decisiones futuras podran validarse contra principios antes de evaluarse por direccion.
- El contenido de The 12 Principles debera incorporarse solo cuando haya sido aprobado.

## Alternativas consideradas

- Mantener los principios dentro de North Star.
- Mantener los principios dispersos dentro de The Care System.
- Usar el Brand Book como fuente para principios permanentes.

Estas alternativas fueron descartadas para preservar una capa documental clara entre filosofia fundacional y direccion estrategica.
