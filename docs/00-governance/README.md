# Governance

Esta carpeta contiene las reglas para mantener la documentacion consistente, trazable y sostenible.

## Documentos

- `documentation-standards.md`: estandares de escritura, versionado y estados.
- `decision-process.md`: proceso para aprobar y registrar decisiones.
- `glossary.md`: terminos oficiales del proyecto.
- `repo-map.md`: mapa de carpetas y responsabilidades.
- `templates/`: plantillas base para nuevos documentos.
