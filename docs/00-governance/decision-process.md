# Decision Process

## Proposito

Establecer como se proponen, aprueban y documentan decisiones dentro del repositorio.

## Flujo

1. ChatGPT o Julius propone contenido, estructura o decision.
2. Julius revisa y aprueba, ajusta o rechaza.
3. Codex convierte la decision aprobada en documentacion mantenible.
4. Las decisiones tecnicas o estructurales relevantes se registran como ADR.
5. Los documentos afectados se enlazan o actualizan.

## Criterios para ADR

Crear un ADR cuando la decision:

- Cambie la arquitectura del repositorio.
- Cambie la arquitectura tecnica del sitio o plataforma.
- Defina una fuente de verdad.
- Afecte la forma de crecer del proyecto a largo plazo.
- Tenga alternativas razonables que deban quedar registradas.

## Roles

- Julius: aprobacion final.
- ChatGPT: redaccion estrategica o conceptual cuando aplique.
- Codex: edicion tecnica, estructura documental, consistencia y versionado.
