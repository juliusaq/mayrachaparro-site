# Repo Map

## Proposito

Explicar donde vive cada tipo de informacion dentro del repositorio.

## Carpetas principales

| Ruta | Responsabilidad |
| --- | --- |
| `child-theme/` | Codigo fuente del tema hijo de WordPress. |
| `docs/` | Documentacion oficial de la plataforma. |
| `prompts/` | Prompts y plantillas para trabajo asistido por IA. |
| `docs/00-governance/` | Normas, procesos, glosario y mapa documental. |
| `docs/01-care-system/` | Fuente filosofica principal del proyecto. |
| `docs/02-strategy/` | Estrategia aprobada de plataforma y productos. |
| `docs/03-brand/` | Marca, voz, mensajes y activos. |
| `docs/04-design/` | Sistema de diseno, tokens, componentes y accesibilidad. |
| `docs/05-ux/` | UX, arquitectura de informacion, journeys y formularios. |
| `docs/06-content/` | Contenido educativo, editorial, SEO y borradores. |
| `docs/07-technical/` | Arquitectura tecnica, WordPress, despliegue e integraciones. |
| `docs/08-adr/` | Registro de decisiones arquitectonicas. |
| `docs/09-roadmap/` | Roadmap, milestones y releases. |
| `docs/10-operations/` | Mantenimiento, QA, analitica e incidentes. |

## Regla de ubicacion

Si un documento puede vivir en mas de una carpeta, debe ubicarse donde sea fuente de verdad primaria y enlazarse desde las demas.
